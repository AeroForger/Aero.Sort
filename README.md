# Aero.Sort;

Aero.Sort is a library for sorting algorithms

## Installation

dotnet add package Aero.Sort

## Usage

using Aero.Sort;

int[] array = { 5, 2, 8, 1, 3 };

array.Quick();

## Algorithms

- Bubble Sort
- Bogo Sort
- Insertion Sort
- Merge Sort
- Quick Sort

## Requirements

.NET 10
